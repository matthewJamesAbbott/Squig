1 · Ingest: any book format → Parquet ocr.py · GPU (PDF/DJVU/comics)

PDF (marker OCR, GPU) plus text extractors (EPUB/TXT/RTF/DOCX/HTML/FB2/CHM, CPU) and converter formats (Kindle→EPUB, DOC/ODT→DOCX, DJVU/CBZ/CBR→PDF→OCR). Format is autodetected per file (magic bytes → extension). One parquet per book, one row per page; text-based books get nominal pages of ~words-per-page, breaking only between paragraphs.
Advanced — marker VRAM tuning (P2000 defaults shown as blanks; set to lower OOM)

2 · Enrich metadata enrich_ddc_collection.py · LLM

One LLM call per book adds final_title / authors / publisher / pub_date / ddc / summary to each parquet (in place) and marks TOC/index pages as is_index. Run this before rename — parquets without metadata are skipped there. Re-runs skip books already enriched.

3 · Rename → DDC tree rename_ddc_collection.py · CPU

Reads metadata from parquets, renames pdf/parquet/images to DDC - title - publisher - author - date and copies into the right DDC folder.

4 · Recipe extraction extract_recipes.py · LLM

Keyword-filters cookbook pages, then uses an OpenAI-compatible LLM to extract recipes + a deduplicated ingredient index (recipes.parquet / ingredients.parquet). Input must contain the parquet files directly (not recursive — pick a DDC sub-dir, e.g. the 641 cooking folder).

5 · Qdrant indexing index_books.py · embeds via Ollama

Embeds all pages (bge-m3) into the ddc-books collection. Idempotent — already-indexed books are skipped, so re-running picks up new books.

🔎 Search the library Qdrant · bge-m3

Semantic search over every indexed page (embeds your query with the same model, queries Qdrant). Requires Ollama up + Qdrant populated.
